Куди встановити гру?

Залиш порожнім, щоб використати теку за замовчуванням legendary (~/legendary).

Налаштування гри

Proton/Wine та інші параметри запуску (актуально для Linux). Записується напряму у config.ini legendary — той самий механізм, яким користується Heroic.

Сам знайде/скачає GE-Proton (офіційний відкритий проєкт), створить префікс, знайде Steam і підготує EAC runtime. BattlEye й ручне тонке налаштування — нижче.

Це справжній запуск через proton (не просто його Wine-бінарник) — саме так працює EAC/BattlEye runtime нижче. Потрібна тека з файлом proton всередині (напр. GE-Proton чи звичайний Proton зі Steam).

Гра запускається напряму, без Wine чи Proton — для нативних Linux-білдів.

Easy Anti-Cheat / BattlEye Runtime (Linux)

Це той самий механізм, яким користується Heroic. Файли розповсюджує Valve безкоштовно через Steam — інструменти Proton EasyAntiCheat Runtime та Proton BattlEye Runtime можна встановити на акаунт і завантажити навіть без жодної гри в Steam. Встанови потрібний(і) один раз, вкажи шлях нижче — далі просто галочка.

⚠ Потребує режиму Proton вище — під звичайним Wine ці змінні нічого не роблять.
Чесно про межі цього. EAC/BattlEye runtime вище працює лише в режимі Proton (не Wine) — це реальна вимога самого Proton, а не примха цього лаунчера: змінні PROTON_EAC_RUNTIME/PROTON_BATTLEYE_RUNTIME читає скрипт proton, а не звичайний Wine-бінарник. Навіть у режимі Proton — це вмикає лише можливість ініціалізації анти-чита, а чи саму гру пропустить конкретний анти-чит-деплой, вирішує розробник на своєму боці. Fortnite Epic блокує на Linux свідомо — це не обійти жодним налаштуванням тут.
